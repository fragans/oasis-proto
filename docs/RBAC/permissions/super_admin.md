# Super Admin Role

The **Super Admin** role is the highest level of authority in the Oasis Dashboard. It provides unrestricted global access to the entire system, including all organizations, users, and configurations.

## Permissions

### Organizations
- **[FULL ACCESS]** Create, view, edit, and delete organizations.
- **[SYSTEM]** Manage global organization settings (hostname, API URLs, etc.).
- **[GLOBAL]** Switch between any organization without restriction.

### Campaigns (On Site Messages)
- **[FULL ACCESS]** Create, view, edit, clone, and delete campaigns across all organizations.
- **[SYSTEM]** Launch, pause, resume, and archive any campaign.
- **[GLOBAL]** View aggregated performance data across the entire platform.

### Creatives
- **[FULL ACCESS]** Upload, view, and delete creative assets globally.
- **[SYSTEM]** Manage system-wide creative templates and resources.

### Audiences & Segments
- **[FULL ACCESS]** Create, view, edit, and delete audience segments across all organizations.
- **[SYSTEM]** Manage global audience criteria and data ingestion settings.

### Team & User Management
- **[FULL ACCESS]** Manage all users in the system.
- **[SYSTEM]** Assign or change roles (including Super Admin) for any user.
- **[SYSTEM]** Ban or unban users and manage security settings.
- **[GLOBAL]** View audit logs and system activity.

## UI Capabilities
Super Admins have full visibility and control over the interface:
- All action buttons and menus are visible.
- Access to the Global View toggle and organization switcher for all entities.
- Access to advanced system settings and debugging tools.
- No API-level restrictions on data fetching or mutations.
